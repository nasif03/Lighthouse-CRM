# Stream Chat Installation

The Stream Chat packages need to be installed. Run this command in the Frontend directory:

```bash
cd Frontend
npm install
```

This will install all packages including:
- `stream-chat@8.15.0`
- `stream-chat-react@11.7.0`

If you get errors, try:
```bash
npm install stream-chat@8.15.0 stream-chat-react@11.7.0 --legacy-peer-deps
```
